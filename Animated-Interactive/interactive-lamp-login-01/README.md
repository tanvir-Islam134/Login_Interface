# Interactive Lamp Login / Signup (`interactive-lamp-login-01`)

A creative and interactive authentication interface featuring an articulated **desk lamp with a pull string / cord**. 

Pulling the cord triggers a tactile mechanical sound and turns on the lamp, casting a vibrant cyan cone of light with floating atmospheric dust particles across the scene, illuminating the hidden Login / Sign Up card!

---

## 📸 Key Features
- **Interactive Pull Cord:** Click or pull down the hanging cord ring to toggle the desk lamp on and off with physics bounce animation.
- **Synthesized Click Sound:** Uses Web Audio API to create an authentic mechanical switch click with zero external audio assets.
- **Illuminated Light Beam:** A glowing cone of light reveals the hidden authentication card from pitch darkness.
- **Floating Dust Particles:** Interactive Canvas-based atmospheric floating particles drifting through the light cone.
- **Dual Tab Support:** Seamless switching between **Sign In** and **Sign Up** modes.
- **Responsive Layout:** Automatically adapts layout for mobile, tablet, and desktop viewports.
- **Zero External Dependencies:** 100% Vanilla HTML5, CSS3, and JavaScript.

---

## 📂 File Structure
- `index.html` - SVG desk lamp, hanging cord, and illuminated form card.
- `style.css` - Light cone clip-path, dark ambient shadows, glowing trims, and pull cord keyframes.
- `script.js` - Web Audio click generator, lamp toggle state, dust canvas animation, and validation.

---

## 🚀 How to Run in VS Code
1. Open this folder in VS Code.
2. Right-click on `index.html`.
3. Select **"Open with Live Server"**.
4. Pull the yellow cord ring to turn on the lamp!
