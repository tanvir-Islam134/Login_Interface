# 🎨 Login Interface Collection

A curated collection of modern, responsive, and beautifully crafted **Login and Authentication Interfaces** built with pure HTML5, CSS3, and JavaScript. 

Each interface is neatly categorized by design style, completely self-contained, and ready to be dropped into any web project.

## 🚀 How to Use Any Interface

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tanvir-Islam134/Login_Interface.git
   cd Login_Interface
   ```

2. **Navigate to the template you want:**
   ```bash
   cd Interactive-Lamp/lamp-login-01
   ```

3. **Open directly in browser:**
   Double-click `index.html` or right-click and select **"Open with Live Server"** in VS Code.

4. **Copy into your project:**
   Each folder is completely standalone. Simply copy the `index.html`, `style.css`, and `script.js` directly into your web project.

## 🛠️ Built With

- **HTML5:** Semantic, accessible markups.
- **CSS3:** Custom properties (CSS variables), Flexbox, 3D Transforms, Backdrop Filter, Keyframe Animations.
- **Vanilla JavaScript:** Fast, lightweight, Web Audio API, Canvas particle animation, zero external dependencies.
