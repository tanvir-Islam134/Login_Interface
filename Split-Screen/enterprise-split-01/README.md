# Enterprise Split-Screen Authentication Interface (`enterprise-split-01`)

An enterprise-grade, high-converting split-screen login interface inspired by industry-leading cloud and SaaS platforms (Stripe, Linear, Supabase, Clerk, Vercel).

---

## 📸 Key Features
- **Split-Screen Architecture:** Left showcase panel highlighting enterprise trust, social proof, and value proposition; right panel for low-friction authentication.
- **Enterprise SSO:** Pre-configured buttons for Google and GitHub single sign-on.
- **Magic Link Support:** Dedicated alternate sign-in flow for passwordless login.
- **Micro-Interactions:** Loading spinner on submit, custom accessible checkbox, password reveal toggle, and toast notifications.
- **Security & Compliance Badges:** Built-in TLS encryption and SOC2 certification indicators.
- **Fully Responsive:** Seamlessly converts into a focused single-column layout on tablet and mobile viewports.
- **Zero External Dependencies:** Built with semantic HTML5, pure CSS3, and modern Vanilla JavaScript.

---

## 📂 File Structure
- `index.html` - Semantic two-column markup with SVG iconography.
- `style.css` - Custom CSS variables, background mesh glow, and responsive media queries.
- `script.js` - Form validation, password toggle, simulated SSO loading, and magic link triggers.

---

## 🚀 How to Run in VS Code
1. Open this folder in VS Code.
2. Right-click on `index.html`.
3. Select **"Open with Live Server"**.
