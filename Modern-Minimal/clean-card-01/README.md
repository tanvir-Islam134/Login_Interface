# Modern Clean Login Interface (`clean-card-01`)

A sleek, pixel-perfect minimalist SaaS login interface inspired by modern enterprise web applications (Stripe, Linear, Vercel).

---

## 📸 Features
- **Clean SaaS Aesthetics:** Subtle borders, delicate shadows, and dot-matrix background grid.
- **Inter Typography:** High legibility font pairing for corporate and software applications.
- **Micro-Interactions:** Loading spinner on submit, animated checkbox, and focus rings.
- **One-Click Password Toggle:** Clean SVG visibility switcher.
- **Social SSO:** Minimalist Google and GitHub authentication buttons.
- **Mobile Responsive:** Adapts seamlessly to small screens.

---

## 📂 File Structure
- `index.html` - Minimal semantic structure and SVG elements.
- `style.css` - Polished CSS variables, typography, and layout rules.
- `script.js` - Input validation, password toggle, and mock asynchronous sign-in.

---

## 🚀 How to Run
Open `index.html` in your browser.
