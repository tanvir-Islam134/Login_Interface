# 3D Flip Login & Registration Interface (`card-flip-3d-01`)

An interactive 3D rotation interface that rotates 180 degrees between **Member Access** and **Profile Registration** using CSS perspective and 3D transforms.

---

## 📸 Key Features
- **3D Perspective Flipping:** Seamless card rotation using `perspective` and `transform: rotateY(180deg)`.
- **Space-Efficient Two-Sided Card:** Sign in on the front face, sign up on the back face.
- **Micro-Interactions:** Subtle focus glows, smooth transitions, and dynamic notifications.
- **Pure Web Technologies:** HTML5, CSS3, and Vanilla JavaScript with zero external scripts.

---

## 📂 File Structure
- `index.html` - Dual-face markup structure.
- `style.css` - 3D transform properties and modern dark palette.
- `script.js` - Card flip trigger handlers and form responses.

---

## 🚀 How to Run
Open `index.html` in any browser.
