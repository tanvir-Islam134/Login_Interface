# Frosted Glass Login Interface (`frosted-glass-01`)

An aesthetic glassmorphism login card with dynamic blurred glowing orbs, semi-transparent frosted glass backdrop, and rich interactivity.

---

## 📸 Features
- **Frosted Glass Card:** High-performance CSS `backdrop-filter: blur(20px)` with subtle border highlight.
- **Ambient Animated Orbs:** Floating gradient orbs in the background that move smoothly.
- **Show/Hide Password:** One-click SVG toggle for password inspection.
- **Social Authentication:** Styled Google and GitHub single sign-on buttons.
- **Form Validation:** Instant feedback on empty or invalid email/password entries.
- **Interactive Feedback:** Toast notification and animated button states.
- **Zero External Dependencies:** Built with pure HTML5, CSS3, and JavaScript.

---

## 📂 File Structure
- `index.html` - Form structure and SVG icons.
- `style.css` - Custom glassmorphic styling, keyframes, and layout.
- `script.js` - Client-side validation, visibility toggle, and submit handling.

---

## 🚀 How to Run
Just open `index.html` in any modern web browser or use VS Code Live Server.
